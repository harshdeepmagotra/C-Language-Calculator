# 🧮 C Language Calculator

A simple and beginner-friendly calculator developed using **C Programming Language** with the **Switch-Case** statement.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User input support
- Menu-driven operations

## 🛠️ Technologies Used

- C Programming Language
- Switch-Case Statement
- GCC Compiler
- Visual Studio Code

## 💻 How to Run

**Step 1:** Clone this repository.

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2:** Compile the program.

```bash
gcc calculator.c -o calculator
```

**Step 3:** Run the program on Windows.

```bash
calculator.exe
```

## 📚 Concepts Learned

- Switch-Case statements
- Arithmetic operators
- User input using scanf()
- Output using printf()
- Basic programming logic

## 🎯 Project Objective

This project was created to practise C programming fundamentals and understand how switch-case statements work in real-world applications.
